# Security Policy

**PLEASE DON'T DISCLOSE SECURITY-RELATED ISSUES PUBLICLY, [SEE BELOW](#reporting-a-vulnerability).**

## Supported Versions

Security fixes are provided for the latest version of this project, package, application, or service.

## Reporting a Vulnerability

If you discover a security vulnerability within AurionMail (see in `security_model` what is in scope), please send an email at github@paulhenry.saux.fr. All security vulnerabilities will be promptly addressed.
